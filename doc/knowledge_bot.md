# 知识驱动 bot（D9 原型：规划层 + 启发式动作层）

日期：2026-10-04。代码 `alpha_poke.agents`；评测 `scripts/eval_bots.py`；队伍池 `scripts/build_team_pool.py`。

## 结构

| 层 | 实现 | 文件 |
|---|---|---|
| 知识层 | 能力值计算（种族值 + 努力值/性格）、伤害估算（STAB/太晶 STAB、属性克制、灼伤、能力等级、天气、讲究/生命宝珠/突击背心、平均伤害浮动）、速度与先后手、1v1 粗估 | `agents/damage.py` |
| 信念层 | 预览：整队条件先验（照搬队伍 → 核心 → 物种 → Smogon）给出对手道具/招式分布；对局中：已暴露信息覆盖先验，配置原型后验重新加权未暴露招式；对手能力值用该物种最常见的 Smogon 努力值配置 | `agents/belief_state.py` |
| 规划层 | 预览时算 6×6 一对一对位表 → 主要威胁、每个威胁的应对者、我方 win condition（含强化手加成）、需保留的宝可梦；首发按对手各宝可梦在 replay 里的首发率加权选择；从套路库匹配对手的核心名称 | `agents/knowledge_player.py` |
| 动作层 | 攻击按预估伤害 + 击倒奖励打分（会被先手击倒时大幅降权）；撒钉/清钉/强化/回复/异常状态/pivot 按适用条件打分；换人按换入后的对位 − 换入承受伤害 + 规划奖励/惩罚 − 换人成本；太晶在能确保击倒或防守翻盘时使用，优先 win condition；异常时回退到 SimpleHeuristics | 同上 |

## 队伍池

从高分 replay 中被照搬 ≥50 次的 40 支队伍重建：道具/特性/太晶取该队伍内最常暴露的值，招式取队伍内暴露最多的（不足 4 个用 Smogon 补），努力值/性格用该物种最常见的 Smogon 配置；Ogerpon 用基础特性（replay 中的 Embody Aspect 是太晶后才有的）。经本地 Showdown 校验，38/40 支合法（`data/teams/pool/`）。

## 消融实验（2026-10-04）

变体：去掉信念层（只用 Smogon 边缘分布，不认整队/核心，不做对局中配置原型更新；已暴露信息仍使用）、去掉规划（威胁/应对者/win condition/保留，首发按文件顺序）、只换首发方式（文件顺序即字母序 / 随机 / 假设对手均匀首发）。每组 2,000 局，**双方轮流发起挑战**；双方回退次数均为 0。

**评测框架的两个坑（已修）**：
1. 只报告了我方的回退次数，"随机首发"变体因 `random` 未导入而每一步都回退到 SimpleHeuristics，一开始得出"规划首发 vs 随机首发 68%"的错误结论。现在双方回退次数都会报告。
2. 由同一方发起所有挑战时存在约 3 个百分点的角色偏差（两个完全相同的 bot 对打，发起方 47.1% ± 2.2%）。改为轮流发起后为 48.9% ± 2.2%。此前未轮流发起的对打数字都应与约 47% 比较。

| 比较 | 完整版胜率（95% CI） |
|---|---|
| vs 去掉信念层 | 49.5% ± 2.2% |
| vs 去掉规划（威胁/应对者/win condition/保留） | 50.8% ± 2.2% |
| vs 首发=文件顺序（字母序） | **45.1% ± 2.2%** |
| vs 首发=随机 | **46.1% ± 2.2%** |
| vs 首发规划假设对手均匀首发 | 48.2% ± 2.2% |
| vs 两层都去掉 | 47.4% ± 2.2% |

| 变体 vs SimpleHeuristics | 胜率 |
|---|---|
| 完整版 | 66.9% ± 2.1% |
| 去掉信念层 | 65.2% ± 2.1% |
| 去掉规划 | 66.8% ± 2.1% |
| 首发=文件顺序 | 67.0% ± 2.1% |
| 首发=随机 | 66.8% ± 2.1% |
| 两层都去掉 | 63.3% ± 2.1% |

**结论**：
- **相对 SimpleHeuristics 的优势主要来自动作层**（伤害模型 + 打分规则）：两层都去掉时仍有 63.3%。
- **信念层和规划层单独都测不出效果**（直接对打都在 50% 附近），合在一起对 SimpleHeuristics 约 +3.6 个百分点（66.9% 对 63.3%，约 2.4 个标准误）。原因很可能是动作层对它们用得很浅：信念只影响对手招式/道具/能力值的估计，规划只提供几个小的奖励和惩罚。
- **规划首发是负贡献**：比随机首发还差约 4 个百分点（46.1% ± 2.2%）；改为假设对手均匀首发后差距缩小到不显著。首发打分里"按人类首发率预测对手首发"、"撒钉手 +0.15"、"win condition −0.15"这些规则需要重新检查。
- 信念层的离线优势（道具 top-1 从 55% 提到 77%）没有转化为对战胜率——这说明下一步的重点应该是**让决策真正利用信念**（例如预测对手这回合的行动、讲究围巾带来的先后手变化、对手可能的太晶），而不是继续提高预测准确率。

## 配对消融（新评测框架，2026-10-04，`scripts/arena.py`）

改进：固定种子的配对赛程（每对队伍打两局并交换队伍、轮换挑战方）、逐局日志与队伍校验、队伍池努力值按 Smogon 分布抽样、另有"陌生队伍"设置（信念模型训练时剔除队伍池里的队伍）。每组 1,000 对 = 2,000 局，平局记 0.5 分；双方回退 0 次，队伍错配 0 次。置信区间为配对估计（比普通估计窄约 10–20%）。

| 比较 | 完整版得分（95% CI） | 平局 |
|---|---|---|
| vs 完全相同的自己（健全性检查） | 48.7% ± 1.7% | 87 |
| vs 去掉信念层 | 51.6% ± 1.9% | 105 |
| vs 去掉规划 | 49.0% ± 1.9% | 38 |
| vs 首发=文件顺序 | 50.2% ± 1.8% | 99 |
| vs 首发=随机 | 49.9% ± 1.8% | 101 |
| vs 首发规划假设对手均匀首发 | 50.3% ± 1.7% | 81 |
| vs 两层都去掉 | 52.0% ± 2.0% | 47 |
| vs 去掉信念层〔陌生队伍〕 | 50.2% ± 1.8% | 84 |

| vs SimpleHeuristics | 得分 |
|---|---|
| 完整版 | 65.3% ± 2.0% |
| 两层都去掉 | 63.7% ± 1.9% |
| 完整版〔陌生队伍〕 | 65.8% ± 2.0% |

**结论（取代上一节的部分结论）**：
- 信念层、规划层、首发方式**都没有可测的效果**（差异都在 ±2 个百分点以内）。
- **撤回"规划首发是负贡献"**：在新框架下首发的三种方式完全持平。之前的 45% 来自未配对设计的噪声，以及当时队伍池的特点（固定努力值、独立随机抽队）。
- 陌生队伍与已知队伍下对 SimpleHeuristics 的表现相同，说明信念层"背答案"也没有带来优势——问题在于动作层几乎没用上信念。
- **知识 bot 之间的对局有 2–5% 打到第 1000 回合平局**（死循环），与 SimpleHeuristics 对局则没有。

## 已知问题与下一步

1. **伤害模型对受队偏乐观**：面对受队时，规划层把几乎所有我方宝可梦都算作"应对者"（没考虑回复、Unaware、剧毒磨血等），需要把回复和持续伤害纳入 1v1 估算。
2. **首发规划**：消融显示它是负贡献，需要重新设计或暂时改为随机/均匀先验。
2b. **让动作层真正利用信念与规划**：预测对手本回合行动（攻击/换人）、按信念处理先后手（围巾）与太晶、对局中重新规划。
3. **更强的对手**：接入 Foul Play（独立 venv、离线补丁）和 Metamon checkpoint 作为评测对手。
4. **换人与长期规划**：目前的计划是静态的（只在预览时计算），对局中应根据倒下、暴露的信息重新规划。
5. 套路库是在解析器修正特性归属之前生成的（`doc/archetype_library.md`），需要重建一次。
